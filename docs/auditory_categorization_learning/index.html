Auditory categorization learning

What changes as a mouse learns to categorize sounds?

Interactive research article · Thesis in progress · September 2026

Choices reveal learning, but they do not uniquely identify the process that produced it. A stable strategy, a gradually changing strategy, and switches between strategies can sometimes explain similar observations. This article connects recorded behavior to the assumptions of each model. The behavioral study and its data are published; the thesis model comparisons shown here are preliminary, and their full analysis code is being prepared for release.

Behavior across training

In an auditory categorization task, a mouse learns to associate sounds with two response categories. The curves below summarize recorded choices across training. Select an animal to see how the course of learning differs between individuals.

Accuracy is only one description of learning. An animal may improve on one category while maintaining a bias toward the other. Separating the two categories makes that asymmetry visible.

Choice-history reinforcement learning

This is the four-parameter choice-history RL model in Collina et al. (2025), implemented from the study’s simulation code. Its parameters are learning rate α, initial value Q₀, choice bias b, and choice-history parameter β. Each outcome updates the chosen value and also changes the unchosen value in the opposite direction.

Defaults use GS027 parameters from a 2026 thesis fit. They are not the paper’s original example fit. Changing a slider generates a new simulation with those settings; it does not refit the recorded mouse data. Reset restores the default fit.

In the published experiment, water-restricted mice were head-fixed and turned a wheel with their forepaws. Correct training responses earned approximately 4–5 μL of water from a lick spout. Here, the model’s reward drives water delivery and an illustrative licking movement. Replay a trial slowly to follow sound, choice, and reward.

Moving the learning rate changes how quickly feedback affects later choices. Moving the initial value changes the starting point. These mechanisms can produce different trajectories even when the final accuracy is similar.

Model equations

For low and high categories, the stimulus vector is respectively (−1, 0) or (0, 1). The model uses

P(high) = logistic[5(s · Q + 2b)]
δ = reward − Qchosen
Qchosen ← Qchosen + αδ
Qunchosen ← Qunchosen − exp(−β)αδ

The factor 5 is fixed in the source implementation. Initial values are (Q₀, −Q₀). The unchosen-update slider displays exp(−β), the effective coupling strength, rather than β itself. At zero coupling, the unchosen value is unchanged, giving the simple-model limit (β → ∞). Larger coupling strengthens the opposing update.

Prediction and simulation

Fitting and simulation ask different questions. During likelihood evaluation, the model updates from the mouse’s recorded choices. During a rollout, it updates from its own generated choices. An early disagreement can therefore change all later values.

The source-notebook view reproduces the original plotting pipeline. The two diagnostic views use the same GS027 parameters and recorded sound sequence to compare prediction with simulation.

A high likelihood alone does not establish that a model reproduces the learning trajectory. Conversely, a visually similar trajectory does not establish accurate trial-level prediction. Both checks are needed; this figure does not demonstrate a general reversal in model rankings.

States across training

Preliminary thesis analysis · Three-state GLM-HMM

Select a mouse to see its inferred state on each trial. Each state has its own relationship between sound and choice. Long stretches of one color indicate a sustained inferred strategy; changes in color indicate a different most likely state.

These are model-inferred states, not directly measured brain or psychological states. Sessions are modeled separately, so a change across a session boundary is not a fitted within-session transition.

Fit and data details

The model uses one signed stimulus weight and one bias per state. Each plotted point is the state with the highest smoothed posterior probability, not a Viterbi path. The readout shows that probability; uncertain trials are still assigned to their most likely state.

The previous choice

Preliminary thesis analysis · Full analysis code not yet released

A choice-history term can capture a tendency to repeat the previous response. A win–stay, lose–switch term distinguishes responses following rewarded and unrewarded trials. Whether these terms help depends on the rest of the model.

This motivates a narrower question: how much apparent history dependence remains after allowing the strategy itself to change? A history coefficient may reflect a direct dependence on recent choices, slower variation in behavior, or a combination of both.

Data and code availability

The data and code associated with Collina et al. (2025) are publicly available: paper code on GitHub and behavioral data on Dryad.

Steven Peng’s thesis analyses are ongoing. The full thesis model-analysis code has not yet been publicly released. The selected preliminary summaries on this page, website implementation, and numerical checks are available in the website repository.

Methods and scope

This first edition contains existing results from 19 mice, an interactive implementation of the reinforcement learning update, and inferred GLM-HMM state sequences for all 19 mice. The browser displays precomputed statistical fits; it does not refit models when you select a mouse. The embodied view is illustrative.

The public site includes summarized analyses, inferred state sequences, and the GS027 stimulus-category and choice sequences from the previously published old-mouse dataset, approved for use in this edition. Internal notebooks and newer unpublished animal data are not included.

The interactive simulator preserves the original function’s N−1 computed trials. Its uncomputed final zero is excluded from playback and the diagnostic. The source-notebook reference preserves the complete original arrays and plotting transforms, including that entry. The notebook seeds NumPy but not Python’s random module, so its historical stochastic realization cannot be recovered from the notebook alone.
