Auditory categorization learning

What changes as a mouse learns to categorize sounds?

Interactive research article · First edition · September 2026

Choices reveal learning, but they do not uniquely identify the process that produced it. A stable strategy, a gradually changing strategy, and switches between strategies can sometimes explain similar observations. This article connects recorded behavior to the assumptions of each model.

Behavior across training

In an auditory categorization task, a mouse learns to associate sounds with two response categories. The curves below summarize recorded choices across training. Select an animal to see how the course of learning differs between individuals.

Accuracy is only one description of learning. An animal may improve on one category while maintaining a bias toward the other. Separating the two categories makes that asymmetry visible.

A learning model

The reinforcement learning model keeps two values, one for each choice. A choice produces an outcome; the difference between that outcome and the current value changes the next decision. The learning rate controls the size of that update.

Here, model choices drive an illustrative mouse and wheel. The learning curves and model values advance on the same trial clock. You can pause, inspect a trial, or change a parameter and replay training.

Moving the learning rate changes how quickly feedback affects later choices. Moving the initial value changes the starting point. These mechanisms can produce different trajectories even when the final accuracy is similar.

Model equations

For low and high categories, the stimulus vector is respectively (−1, 0) or (0, 1). The model uses

P(high) = logistic[5(s · Q + 2b)]
δ = reward − Qchosen
Qchosen ← Qchosen + αδ
Qunchosen ← Qunchosen − exp(−β)αδ

The factor 5 is fixed in the source implementation. β controls the unchosen update, not the choice temperature. Initial values are (q, −q).

Prediction and simulation

Fitting and simulation ask different questions. During likelihood evaluation, the model updates from the mouse’s recorded choices. During a rollout, it updates from its own generated choices. An early disagreement can therefore change all later values.

The source-notebook view reproduces the original plotting pipeline. The two diagnostic views use the same GS027 parameters and recorded sound sequence to compare prediction with simulation.

A high likelihood alone does not establish that a model reproduces the learning trajectory. Conversely, a visually similar trajectory does not establish accurate trial-level prediction. Both checks are needed; this figure does not demonstrate a general reversal in model rankings.

How strategies change

Three statistical models describe change at different levels. Static logistic regression uses fixed weights. PsyTrack allows weights to vary smoothly. A GLM-HMM uses several sets of weights and a latent process that switches among them.

Predictive improvement supports the usefulness of a model’s flexibility under this evaluation. It does not establish that the animal’s internal learning process has the same form. The state labels should be interpreted as model inferences.

The previous choice

A choice-history term can capture a tendency to repeat the previous response. A win–stay, lose–switch term distinguishes responses following rewarded and unrewarded trials. Whether these terms help depends on the rest of the model.

This motivates a narrower question: how much apparent history dependence remains after allowing the strategy itself to change? A history coefficient may reflect a direct dependence on recent choices, slower variation in behavior, or a combination of both.

Methods and scope

This first edition contains existing results from 19 mice, an interactive implementation of the reinforcement learning update, and a complete one-weight cross-validation comparison for GS029. It does not refit the statistical models or provide a connectome or biomechanical simulation.

The public site includes summarized analyses and the GS027 stimulus-category and choice sequences from the previously published old-mouse dataset, approved for use in this edition. Internal notebooks and newer unpublished animal data are not included.

The interactive simulator preserves the original function’s N−1 computed trials. Its uncomputed final zero is excluded from playback and the diagnostic. The source-notebook reference preserves the complete original arrays and plotting transforms, including that entry. The notebook seeds NumPy but not Python’s random module, so its historical stochastic realization cannot be recovered from the notebook alone.
